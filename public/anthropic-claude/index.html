The environment

Connect the task to the right Claude environment.

Claude supports work such as drafting, analyzing documents, and creating artifacts. Claude Code is an agentic coding tool for working with a codebase. The Claude API provides another route for building an application or connected workflow.

An employee workspace, a coding environment, and an API application need different access and operating arrangements. We clarify which are in scope, what information they may use, and who reviews their output.

How RUDI helps

Choose the support your team needs.

Hands-on Claude training

Practice turning a work request into a clear brief, selecting relevant documents, and reviewing the result. Build reusable instructions for tasks such as preparing an internal brief or comparing proposals, using approved practice material.

Workspace and connector setup

Work with your administrators on accounts, roles, approved connections, and shared working instructions. Check the permissions in the source system as well as the AI workspace. Document where users go for help and how changes are approved.

Claude Code and application development

Help a team scope a small application or an agent-assisted development workflow. Define project instructions, permitted files and tools, test requirements, and human code review. API-based work includes its own usage, access, and maintenance plan.

An example to scope with your team

Prepare an evidence-based comparison of proposals.

A department has two proposals to compare against agreed criteria. Claude can help prepare the comparison while the decision owner checks the supporting evidence and resolves missing information.

  1. 01Approved documents

    Use current proposals and the team’s criteria.

  2. 02Claude-assisted comparison

    Draft a table with source references and questions.

  3. 03Decision owner review

    Verify prices, assumptions, omissions, and trade-offs.

  4. 04Decision brief

    Save the reviewed comparison for discussion.

For recurring work, we can assess whether a saved set of instructions, a connected workflow, or a small application is the appropriate next step. A managed digital worker needs a defined job, permitted actions, an exception process, and a responsible human manager.

Discuss an implementation pilot

Responsible AI

Keep a person responsible for the work.

Agree on approved information, access, review, and disclosure before the pilot begins. For an agent that can take actions, define what needs approval, where it must stop, and who resolves exceptions. Configure those limits in the tools and workflow.

RUDI’s RESPECT framework covers responsible ownership, equitable access, safety, privacy, efficiency and effectiveness, control, and transparency. Evaluate the result with the people who will use it.

Ongoing support can include accessible practice, office hours, workspace administration, or operation of a managed digital worker. The proposal defines the responsibilities and schedule.
