Context for the collection

About these lessons and when they were recorded.

This collection was recorded in 2025. The core ideas—human judgment, model limitations, prompt structure, memory, tools, and workflow design—remain central to responsible AI practice.

Product interfaces and model controls change quickly, so treat on-screen demonstrations as examples of the method rather than permanent instructions for a specific tool.
