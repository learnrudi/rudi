# Public website copy

Write headings that tell readers what a section covers or what RUDI helps them do.
Name the work, the people involved, and the result they can expect.

- Prefer “What we assess before you invest in AI” to “Readiness is a system, not a score.”
- Explain the activity behind an abstract claim: interviews, workflow review,
  training, testing, decisions, or ongoing support.
- Avoid slogans built around “not X, but Y,” repeated sentence fragments, and
  unsupported claims about what every organization needs.
- Preserve useful distinctions, attributed quotations, evidence, and limitations.
  A factual contrast does not need to be removed simply because it contains “not.”
- Keep page titles, social descriptions, structured data, and internal link labels
  consistent when revising a headline.
- Review short headings in context on desktop and mobile. Copy edits must preserve
  URLs, forms, navigation, source links, and published measurements.

Use the synthetic-cadence-editor skill for editorial review. Existing Daily
editions contain dated reporting and attributed source claims; review those in
their reporting context rather than applying global word substitutions.
